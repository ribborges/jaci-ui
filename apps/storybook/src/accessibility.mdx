# Accessibility

Jaci UI uses semantic HTML and Base UI primitives for focus management, keyboard interaction and
ARIA behavior in interactive components. Consumers should still provide the information that only
the application knows, such as accessible labels, descriptions and error messages.

## Application checklist

- Give icon-only triggers an accessible `aria-label`.
- Associate `Field.Label`, descriptions and errors with the relevant control.
- Keep visible focus indicators enabled and do not remove outlines globally.
- Use `aria-live` only for status updates that users need announced.
- Keep a logical heading hierarchy and use semantic links for navigation.
- Test keyboard navigation at mobile and desktop breakpoints.

The Storybook a11y addon runs against the component catalog and treats violations as errors. Add a
story for every meaningful disabled, invalid, loading, selected and empty state.

## Custom accent colors

When an application overrides `--jaci-colors-accent-default`, it should also provide a hover color
and verify the contrast of `--jaci-colors-fg-on-accent` against the chosen accent background.

```css
:root {
  --jaci-colors-accent-default: #7c3aed;
  --jaci-colors-accent-hover: #6d28d9;
  --jaci-colors-fg-on-accent: #ffffff;
}
```
