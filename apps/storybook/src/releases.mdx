# Releases

The published package is `jaci-ui`. The root workspace version is private and is not published.

## Change workflow

Create a Changeset for every public API, behavior, accessibility or styling change:

```sh
pnpm changeset
```

Choose `patch` for a fix, `minor` for a backwards-compatible feature and `major` for a breaking
change. The release workflow opens a version pull request after changes reach `main`. Merge that
pull request, then run the `Publish package` workflow after CI succeeds.

The npm workflow uses GitHub Actions Trusted Publishing/OIDC. No long-lived npm token belongs in
the repository or in GitHub secrets.
