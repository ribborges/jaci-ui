# Versioning

`0.9.x` is an experimental API-freeze line. The first version considered stable will be `1.0.0`.

Changesets is the source of truth for versions. The candidate is published with:

```sh
pnpm changeset pre enter rc
pnpm release:version
npm publish --tag rc
```

The candidate package uses `0.9.0-rc.0`, followed by `rc.1`, `rc.2` and so on for fixes. After
consumer validation, prerelease mode is exited and `0.9.0` is published with the `latest` tag.

There is no migration guide at this stage: the library is still experimental and has no stable
consumer base before `1.0.0`.
