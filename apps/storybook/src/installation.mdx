# Installation

Install the React package with your package manager and import the generated stylesheet once
from the entry point of your application.

<pre>import "jaci-ui/styles.css";</pre>

Jaci UI uses React as a peer dependency and supports React 18.2 and React 19.

For Next.js, import the CSS from the root layout. For Vite or React Router, import it from
the application entry module.
